# Koltuk Altina Kacan Kumandanin Arama Emri

Bu depo, evin icinde kaybolan uzaktan kumandanin **resmi arama emrini** uretir.

Kumandayi bulmaz. Sadece evrak uretir. Evrak bulununca kumanda zaten oradadir; bu bilimsel olarak kanitlanmamistir ama tutanakta yazmaktadir.

## Neden vardir?

Cunku:

1. Kumanda koltuk altina kacar.
2. Vatandas yastigi kaldirmaz.
3. Devlet (bu depo) araya girer.
4. Evrak basilir.
5. Kimse evraki okumaz.
6. Kumanda yine oradadir.

Bu dongu ISO-KLTK-404 standardina uygundur.

## Kurulum

```bash
python3 arama_emri.py --sahip "Ahmet" --marka "Evrensel-47"
```

Cikti bir arama emridir. Yazdiriniz. Yastiginin altina koyunuz. Belki kumanda evraki gorunce teslim olur.
